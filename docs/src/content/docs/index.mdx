## Why TS-Git

<CardGrid stagger>
  <Card title="Pluggable filesystem" icon="setting">
    Everything goes through a small `FSAdapter` interface. Use the bundled
    in-memory `MemoryFS`, or wrap Node's `fs`, Tauri, the File System Access
    API or anything else.
  </Card>
  <Card title="Runs in the browser" icon="rocket">
    No native bindings and no child processes. Hashing uses Web Crypto and
    compression uses `fflate`, so the same code runs in browsers, workers and
    Node.js.
  </Card>
  <Card title="Works with real repos" icon="seti:git">
    Reads and writes the standard `.git` layout: loose objects, packfiles, refs
    and index v2/v3. Interoperability tests check the results against the
    canonical Git CLI.
  </Card>
  <Card title="Fully typed" icon="seti:typescript">
    Written in strict TypeScript. Every command, option and result is typed,
    from `StatusRow` to `DiffResult`.
  </Card>
  <Card title="Clone, fetch, push, pull" icon="cloud-download">
    Speaks Git's smart HTTP protocol over `fetch`, with auth callbacks and
    CORS-proxy support. Packs, `FETCH_HEAD` and merge commits match what
    canonical Git produces byte for byte.
  </Card>
  <Card title="Bring your own diff" icon="document">
    Line diffing is pluggable through `LineDiffAlgorithm`. Install
    `@keydown-app/ts-git-diff-myers` for a Myers implementation.
  </Card>
  <Card title="Embeddable CLI" icon="seti:shell">
    `@keydown-app/ts-git/cli` turns `git status` and `git commit -m ...`
    strings into results, so you can drop a Git terminal into your app.
  </Card>
</CardGrid>

</Reveal>

## Quick start

<p class="tsg-lede">Install the package, pick a filesystem adapter and point a <code>GitClient</code> at a directory.</p>

```bash
npm install @keydown-app/ts-git
```

```typescript
import { GitClient, MemoryFS } from '@keydown-app/ts-git';

const fs = new MemoryFS();
const git = new GitClient({ fs, dir: '/my-repo', defaultBranch: 'main' });

await git.init();
await fs.writeFile('/my-repo/README.md', '# My Project\n');
await git.add('README.md');

const oid = await git.commit('Initial commit', {
  name: 'Ada Lovelace',
  email: 'ada@example.com',
});

const [latest] = await git.log(1);
console.log(oid === latest.oid); // true
```

## Quick start

<p class="tsg-lede">Install the package, pick a filesystem adapter and point a <code>GitClient</code> at a directory.</p>

```bash
npm install @keydown-dev/ts-git
```

```typescript
import { GitClient, MemoryFS } from '@keydown-dev/ts-git';

const fs = new MemoryFS();
const git = new GitClient({ fs, dir: '/my-repo', defaultBranch: 'main' });

await git.init();
await fs.writeFile('/my-repo/README.md', '# My Project\n');
await git.add('README.md');

const oid = await git.commit('Initial commit', {
  name: 'Ada Lovelace',
  email: 'ada@example.com',
});

const [latest] = await git.log(1);
console.log(oid === latest.oid); // true
```
